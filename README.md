# HydroScan V1

HydroScan V1 is a smart marine buoy designed for real-time water quality monitoring in coastal and marine environments.

The system integrates multiple sensors to measure key environmental parameters, including:

* Salinity
* Water temperature

Collected data is processed by an embedded controller and transmitted wirelessly through RF communication for remote monitoring and analysis.

## Main Features:

* Real-time environmental monitoring
* RF telemetry communication
* Low-power embedded electronics
* Modular sensor architecture
* Designed for marine deployments

## Applications:

* Coastal monitoring
* Marine research
* Aquaculture
* Environmental assessment
* Water quality studies
